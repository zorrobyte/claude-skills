# claude-skills

Claude Code skills, written by agents for agents.

| Skill | What it does |
|---|---|
| [expo-sim-drive](expo-sim-drive/SKILL.md) | Drive an Expo/React Native iOS app headlessly in the simulator: build, install, inject AsyncStorage state fixtures, deep-link, tap via idb, screenshot every screen/state (dark mode, dynamic type, onboarding mid-steps, pro/free tiers) with no human and no Simulator UI. |
| [uiscan](uiscan/SKILL.md) | Walk every screen of a native iOS (Swift/XCUITest) app on a throwaway simulator and return labelled **contact sheets** — one image per ~10 screens, so a visual review costs a handful of reads instead of dozens. |

Install: copy a skill directory into `~/.claude/skills/`.
